# اپلیکیشن اندروید دفتر املاک

این پروژه Android Studio یک پوسته اندرویدی برای پنل افزونه WordPress «Daftar Melk Office» است و به `https://amirb1206.ir` متصل می‌شود.

## امکانات
- ورود از صفحه ورود اختصاصی پنل مشاوران وردپرس؛ نشست ورود با کوکی‌های WebView نگه داشته می‌شود.
- بارگذاری صفحات واقعی پنل و استفاده از سطح دسترسی سمت سرور افزونه؛ اطلاعات حساس در خود اپلیکیشن ذخیره نمی‌شوند.
- ظاهر نزدیک به نمونه مرجع: زمینه روشن، تأکید آبی، کارت‌های گرد، حذف زیرخط لینک‌ها و تصاویر مربع در کارت‌های آگهی.
- دکمه بازگشت اندروید، نوار پیشرفت، انتخاب فایل برای فرم‌های بارگذاری عکس.
- فقط دامنه amirb1206.ir داخل اپ باز می‌شود؛ پیوندهای دامنه‌های دیگر در مرورگر بیرونی باز می‌شوند.

## پیش‌نیاز
- Android Studio جدید
- Android SDK Platform 35
- JDK 17 یا جدیدتر
- اتصال اینترنت برای دریافت Android Gradle Plugin در اولین build

## ساخت APK
1. فایل ZIP را استخراج کنید.
2. Android Studio را باز کنید و پوشه `DaftarMelkAndroid` را با گزینه **Open** انتخاب کنید.
3. صبر کنید Gradle Sync کامل شود.
4. از منوی **Build > Build APK(s)** استفاده کنید.
5. APK آزمایشی معمولاً در مسیر `app/build/outputs/apk/debug/app-debug.apk` ساخته می‌شود.

برای APK قابل انتشار، از **Build > Generate Signed Bundle / APK** استفاده کنید و کلید امضای خود را بسازید و امن نگه دارید.

## نکته مهم درباره اتصال سایت
این برنامه از صفحات ورود و پنل موجود در افزونه استفاده می‌کند، از جمله `/ورود-پنل/` و `/پنل-مدیریت/`. پیش از انتشار، مطمئن شوید افزونه Daftar Melk Office روی سایت فعال است، صفحات ورود و پنل ساخته شده‌اند، گواهی HTTPS معتبر است و ورود مشاوران در مرورگر گوشی کار می‌کند. اگر مسیرهای سفارشی پنل در تنظیمات وردپرس متفاوت باشند، مقدار `START` در `MainActivity.java` باید به‌روزرسانی شود.

## وضعیت خروجی
این فایل شامل **پروژه کامل Android Studio** است. در محیط فعلی Android SDK و Gradle نصب نیستند؛ بنابراین APK باینری از این محیط ساخته یا آزمایش نشده است. فایل APK را با مراحل بالا تولید کنید. این پروژه نیز هنوز روی دستگاه واقعی آزمایش نشده است.
